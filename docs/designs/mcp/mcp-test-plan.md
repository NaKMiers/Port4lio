## Affected Pages/Routes
- `POST /api/mcp`: the new server. Check token checks, scope-filtered tool and prompt lists, refused calls, and every tool's happy path and errors.
- `POST /api/whiteboard/mcp` (alias): check that old `wbt_` tokens and the old tool names still work for one release.
- `GET /api/whiteboard/context.md`: check it accepts `p4_` with read, and `wbt_` during the alias release.
- `/admin/agents`: check token create (shown once), scope checkboxes (publish and pii off by default), revoke (including legacy tokens), and the AgentAction feed.
- `/admin/blog/<id>` editor: check the stale-save banner (R9) after an agent edit.
- `/blog`, `/blog/<slug>`, `/sitemap.xml`, `/blog/rss.xml`: check they refresh after every mutating MCP blog tool, under `next start`.
- `/cv` and `/`: check they refresh after `update_profile`, and that the resume is never agent-written (R8).

## Key Interactions to Verify
- Create a p4_ token with read only, then check that `tools/list` shows only read tools and calling `publish_post` gives an isError plus a refused row in the feed (R1).
- Run scene 1 in Claude Code, check each step's result, then publish it:

  ```
  create_draft -> lint_draft -> illustrate_post -> poll get_post -> publish_post
  ```
- Edit a post via `update_post` edits on a two-page post; its tail stays intact (R6).
- `generate_image` (return mode), then insert `![alt](url)` into a live post (R7).
- Weekly briefing: numbers match /admin/metrics and the blog board for the same window.

## Edge Cases
- Two `illustrate_post` calls at once: the second gets "already running". An editor edit made during a run survives (R3).
- The same clientRef twice at the same moment: one runs, one gets "still running". After a refusal, the same clientRef runs again (R4).
- A token over its image budget: refused, while the editor on the same IP still works (R5).
- A month briefing: the test-funnel section is omitted with a reason (TestEvent 21-day TTL).
- A slug clash with a soft-deleted post: isError suggesting `-2`, no post created (C9).
- An archived post that was once published: unarchive refused with a pointer to `publish_post` (C11).
- A `wbt_` token on `/api/mcp`: 401.
- `find_order`: no output ever contains a seeded customer email or certificate name.

## Critical Paths
- Scene 1 end to end, under `next start`, including the post being public and fresh.
- The regression suites stay green and unmodified through the extraction: `blog-patch`, `blog-kinds`, `blog-series`, `blog-image-prompt`, `blog-permanent-delete`, `blog-post-data`, and the new `profile-route`, `ccaf-route`, `admin-metrics-route` (R10).
- `retention.test.ts` passes with the AgentAction TTL index and the new indexes (R11).

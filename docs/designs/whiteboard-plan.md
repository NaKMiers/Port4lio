Generated by /plan-eng-review on 2026-09-23
Branch: main

Feature: /admin/whiteboard (docs/designs/whiteboard.md)

## Affected Pages/Routes

- /admin/whiteboard - canvas: draw every form, frames, labelled arrows, inspector, autosave pill
- /admin (hub) - new Whiteboard board card links in
- /api/admin/whiteboard/* - owner-only; must 401/redirect without the cookie
- /api/whiteboard/context.md and /api/whiteboard/mcp - bearer token only; cookie must NOT open them

## Key Interactions to Verify

- Draw text/todo/shape/frame/ink, reload, everything is back in place (children inside frames)
- Drag a frame: children move with it
- Drop a card into a frame and drag it out; out of a HIDDEN frame it shows the EyeOff badge
- Double-click an arrow to edit its label
- Delete key on items opens confirm with counts; edges-only delete has no confirm
- Download backup, delete a frame, Restore from backup (preview counts, confirm), it all returns
- Export to AI drawer: scopes, live preview, excluded-items notice, Copy disabled when empty
- Un-hide a hidden frame: confirm with "N items become agent-readable", both buttons
- Token panel: create shows token once, list never shows it again, revoke works, connect command is single-quoted ${VAR}

## Edge Cases

- Fast gesture: frame + child drawn before the frame saves (no rejected card)
- Go offline mid-edit: pill shows Failed - retry, beforeunload warns, recovers when back online
- Large board with many ink strokes: load is quick, pan/zoom stays smooth
- Vietnamese text with diacritics is found by MCP search
- Phone width: drawing tools hidden with the note; pan/zoom/inspector still work

## Critical Paths

- Card persists after autosave + reload
- Delete frame -> restore from backup -> frame, children and links back
- Hidden card never appears in the drawer, context.md or any MCP tool
- Fresh Claude Code session answers "what are my active goals?" via get_overview
